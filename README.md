# COMPASS

**Clinical Oncology Monitoring and Patient Adaptive Support System**

COMPASS is an early-stage research prototype for frequent patient-reported monitoring, clinician-approved guidance, traceable alerting, and low-burden nurse review during oncology care.

> This public repository must never contain patient data, credentials, restricted clinical material, or deployment secrets.

Development follows short, releasable milestones. Product and clinical decisions are specified before implementation; Codex implements approved work on short-lived milestone branches.
